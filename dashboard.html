Project Journey & Retry Loops

From challenge brief to live deployed bot — 11 steps & 2 deliberate retry loops

Source: PDF Page 6 & 7
Phase 1: Architecture

Built 5 endpoints in Flask with in-memory versioned store. Designed 25 seed trigger composers without runtime LLM dependency.

Phase 2: Adversarial Passes

Pass 1: 10 unhandled triggers given dedicated composers.
Pass 2: Reordered reply state machine to check intent before auto-reply to prevent handoff failure.

Phase 3: Retry Loops

Loop 1: Sandbox network/API quotas -> fallback to local deterministic rubric engine.
Loop 2: Werkzeug Windows socket collision -> switched to waitress WSGI runner.

Phase 4: Deployment

Squashed secret-free git commit. Deployed on Render with dynamic $PORT binding. Verified live with test_live.py.
